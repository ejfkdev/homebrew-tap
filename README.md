# ejfkdev/homebrew-tap

[中文文档](README.zh-CN.md)

Homebrew tap for ejfkdev CLI tools.

## Usage

```bash
# Install a tool directly
brew install ejfkdev/tap/dj
brew install ejfkdev/tap/udf
brew install ejfkdev/tap/apix
brew install ejfkdev/tap/tspc
brew install ejfkdev/tap/vcc
brew install ejfkdev/tap/zaip
brew install ejfkdev/tap/saw
brew install ejfkdev/tap/dns
brew install ejfkdev/tap/oss
brew install ejfkdev/tap/jd
brew install ejfkdev/tap/dae
brew install ejfkdev/tap/ov

# Or tap first, then install
brew tap ejfkdev/tap
brew install dj
```
